# 策略梯度算法

Q-learning、DQN 及 DQN 改进算法都是 Value-based 的方法，其中 Q-learning 是处理有限状态的算法，而 DQN 可以用来解决连续状态的问题。但是基于值函数的方法都只能处理离散动作空间，而 Policy-based 的方法直接优化策略，可以处理连续动作空间的优化问题。

对比两者，基于值函数的方法主要是学习值函数，然后根据值函数导出一个策略，学习过程中并不存在一个显式的策略；而基于策略的方法则是直接显式地学习一个目标策略。本节将简单回顾策略梯度算法。

策略梯度方法则选择直接参数化策略 πθ(a∣s)\pi_\theta(a|s)πθ​(a∣s)。其中 θ\thetaθ 是策略网络参数。优化目标是让策略在状态 sss 下更倾向于选择能带来高回报的动作 aaa。策略梯度的基本形式可以写为：

∇θJ(θ)=E[∇θlog⁡πθ(at∣st)At]\nabla_\theta J(\theta)=\mathbb{E}\left[\nabla_\theta \log \pi_\theta(a_t|s_t) A_t\right] \\ ∇θ​J(θ)=E[∇θ​logπθ​(at​∣st​)At​]

其中 AtA_tAt​ 是优势函数，用来衡量动作 ata_tat​ 相对于当前状态平均水平到底好多少。其中优势函数一般写为 Qπ(st,at)−Vπ(st)Q_{\pi}(s_t,a_t)-V_{\pi}(s_t)Qπ​(st​,at​)−Vπ​(st​)，即当前动作价值与当前状态价值的差值。

该梯度公式表明：

  • 如果 At>0A_t>0At​>0，说明这个动作比平均水平更好，应该提高该动作的概率。
  • 如果 At<0A_t<0At​<0，说明这个动作比平均水平更差，应该降低该动作的概率。

上述梯度公式中，包含当前动作的动作价值，还有状态价值。如果采用蒙特卡洛搜索方法来估计，那就是 REINFORCE 算法。

由于使用蒙特卡洛方法，REINFORCE 算法的梯度估计是无偏的，但是方差很大，可能会造成一定程度上的不稳定，这也是 Actor-Critic 算法要解决的问题。Actor-Critic 算法使用动作价值函数代替蒙特卡洛算法来估计回报，属于有偏估计，但方差小，训练更加稳定。

Actor-Critic 算法采用两个网络：分别是 Actor（策略网络）和 Critic（价值网络），对应策略梯度公式中的 πθ\pi_{\theta}πθ​ 与 VπV_{\pi}Vπ​。

  • Actor 与环境交互，并在 Critic 价值函数的指导下用策略梯度学习一个更好的策略。
  • Critic 通过 Actor 与环境交互收集的数据学习一个价值函数，这个价值函数会用于判断在当前状态什么动作是好的，什么动作不是好的，进而帮助 Actor 进行策略更新。

关于 Actor-Critic 的其他变体算法，可参考之前的博客，这里不再赘述。


# TRPO 算法

REINFORCE 与 Actor-Critic 都属于比较直接的策略梯度方法。它们的基本思路是估计策略梯度，然后沿着提高期望回报的方向更新策略参数。这个思路本身没有问题，但在深度强化学习中会遇到一个很现实的困难：策略更新幅度不好控制。

如果学习率太小，策略变化很慢，样本利用效率较低；如果学习率太大，策略可能在一次更新后发生明显偏移。由于策略直接决定智能体如何采样动作，一次过大的策略更新可能会让智能体从一个尚可的策略突然跳到一个很差的策略，导致训练过程剧烈震荡甚至性能崩溃。

TRPO（Trust Region Policy Optimization，信赖域策略优化）就是为了解决这个问题提出的。

策略梯度方法本质是优化策略 π\piπ 的期望回报：

η(π)=Es0,a0,…[∑t=0∞γtr(st)]\eta(\pi) = \mathbb{E}_{s_0, a_0, \dots} \left[ \sum_{t=0}^{\infty} \gamma^t r(s_t) \right] η(π)=Es0​,a0​,…​[t=0∑∞​γtr(st​)]

有研究指出，新策略 π~\tilde{\pi}π~ 的期望回报等于旧策略的期望回报 + 新策略在旧策略优势函数上的累计期望，即：

η(π~)=η(π)+Es0,a0,⋯∼π~[∑t=0∞γtAπ(st,at)]\eta(\tilde{\pi}) = \eta(\pi) + \mathbb{E}_{s_0, a_0, \dots \sim \tilde{\pi}} \left[ \sum_{t=0}^{\infty} \gamma^t A_{\pi}(s_t, a_t) \right] η(π~)=η(π)+Es0​,a0​,⋯∼π~​[t=0∑∞​γtAπ​(st​,at​)]

这里的 Aπ(st,at)A_{\pi}(s_t, a_t)Aπ​(st​,at​) 是旧策略 π\piπ 的优势函数，默认情况下是对应动作价值与状态价值的差值。所以 TRPO 希望通过估计新策略在旧策略优势函数上的期望来评估新策略的性能提升。

经过数学推导（此处略去），上述式子可以推导得到如下形式：

η(π~)=η(π)+∑sρπ~(s)∑aπ~(a∣s)Aπ(s,a)\eta(\tilde{\pi}) = \eta(\pi) + \sum_{s} \rho_{\tilde{\pi}}(s) \sum_{a} \tilde{\pi}(a|s) A_{\pi}(s,a) η(π~)=η(π)+s∑​ρπ~​(s)a∑​π~(a∣s)Aπ​(s,a)

其中 $$\rho_{\tilde {\pi}}(s)$$ 是新策略 π~\tilde{\pi}π~ 访问状态 sss 的概率。所以，当我们需要估计新策略的期望回报时，依赖于新策略的采样数据来估计状态访问分布 ρπ~(s)\rho_{\tilde{\pi}}(s)ρπ~​(s)。显然这种方式在实际训练中是不可行的，因为每次尝试一个新策略都要重新采样大量数据代价太高。因此，引入一个技巧和简化，即当新旧策略足够接近时，可以用旧策略的状态访问分布 ρπ(s)\rho_{\pi}(s)ρπ​(s) 来近似新策略的状态访问分布 ρπ~(s)\rho_{\tilde{\pi}}(s)ρπ~​(s)，从而得到一个替代目标：

Lπ(π~)=η(π)+∑sρπ(s)∑aπ~(a∣s)Aπ(s,a)L_{\pi}(\tilde{\pi})=\eta(\pi) + \sum_{s} \rho_{\pi}(s) \sum_{a} \tilde{\pi}(a|s) A_{\pi}(s,a) Lπ​(π~)=η(π)+s∑​ρπ​(s)a∑​π~(a∣s)Aπ​(s,a)

TRPO 通过 KL 散度来衡量两个策略的差异：

DKL(P∣∣Q)=Ep[log⁡P(x)Q(x)]=∑ipilog⁡piqiD_{KL}(P||Q) = \mathbb{E}_p\left[\log\frac{P(x)}{Q(x)}\right] = \sum_i p_i \log\frac{p_i}{q_i} DKL​(P∣∣Q)=Ep​[logQ(x)P(x)​]=i∑​pi​logqi​pi​​

由于 TRPO 使用上述替代目标来近似新策略的期望回报，因此需要保证新旧策略足够接近，所以通过限制新旧策略之间的 KL 散度来实现这一点：

Eπ[DKL(π(⋅∣s)∥π~(⋅∣s))]≤δ\quad\mathbb{E}_{\pi}\left[D_{KL}\left(\pi(\cdot|s)\|\tilde{\pi}(\cdot|s)\right)\right]\le \delta Eπ​[DKL​(π(⋅∣s)∥π~(⋅∣s))]≤δ

其中 δ\deltaδ 是一个小的超参数，表示允许的新旧策略之间的最大 KL 散度。

回到上述替代目标，TRPO 优化策略时本质上是优化下面目标：

Lπ(π~)=η(π)+Es∼ρπ,a∼π~[Aπ(s,a)]L_{\pi}(\tilde{\pi})=\eta(\pi)+\mathbb{E}_{s\sim \rho_{\pi}, a\sim \tilde{\pi}}\left[A_{\pi}(s,a)\right] Lπ​(π~)=η(π)+Es∼ρπ​,a∼π~​[Aπ​(s,a)]

上述优化目标中，动作需要在新策略 π~\tilde{\pi}π~ 下采样，这意味着无法直接使用旧策略采样得到的数据来估计这个目标。为了解决这个问题，TRPO 引入重要性采样，对动作分布进行修正：

Lπ(π~)=η(π)+Es∼ρπ,a∼π[π~(a∣s)π(a∣s)Aπ(s,a)]L_{\pi}(\tilde{\pi})=\eta(\pi)+\mathbb{E}_{s\sim \rho_{\pi}, a\sim \pi}\left[\frac{\tilde{\pi}(a|s)}{\pi(a|s)} A_{\pi}(s,a)\right] Lπ​(π~)=η(π)+Es∼ρπ​,a∼π​[π(a∣s)π~(a∣s)​Aπ​(s,a)]

整理上述推导过程，TRPO 训练过程等价于求解如下优化问题：

max⁡π~Es∼ρπ,a∼π[π~(a∣s)π(a∣s)Aπ(s,a)]s.t.Eπ[DKL(π(⋅∣s)∥π~(⋅∣s))]≤δ\max_{\tilde{\pi}} \mathbb{E}_{s\sim \rho_{\pi}, a\sim \pi}\left[\frac{\tilde{\pi}(a|s)}{\pi(a|s)} A_{\pi}(s,a)\right]\\ \quad \text{s.t.} \quad\mathbb{E}_{\pi}\left[D_{KL}\left(\pi(\cdot|s)\|\tilde{\pi}(\cdot|s)\right)\right]\le \delta π~max​Es∼ρπ​,a∼π​[π(a∣s)π~(a∣s)​Aπ​(s,a)]s.t.Eπ​[DKL​(π(⋅∣s)∥π~(⋅∣s))]≤δ

直接求解上式带约束的优化问题比较麻烦，TRPO 在其具体实现中做了一步近似操作来快速求解，包括共轭梯度、近似搜索等。这部分理论推导比较复杂，由于笔者精力有限，这部分内容就不再展开，详细可见动手学强化学习 TRPO 算法。


# PPO 算法原理

TRPO 算法在很多场景上的应用都很成功，但是它的计算过程非常复杂，每一步更新的运算量非常大。于是，TRPO 算法的改进版 PPO 算法在 2017 年被提出。PPO 基于 TRPO 的思想，但是其算法实现更加简单。并且大量的实验结果表明，与 TRPO 相比，PPO 能学习得一样好（甚至更快），这使得 PPO 成为非常流行的强化学习算法。

PPO 基于 TRPO 简化而来，本质想要求解的优化问题与 TRPO 是一致的，见上一节的推导结果。

针对 TRPO 的优化问题，PPO 用了一些相对简单的方法来求解。具体来说，PPO 有两种形式，一是 PPO - 惩罚，二是 PPO - 截断，我们接下来对这两种形式进行介绍。

# PPO-Penalty

PPO - 惩罚（PPO-Penalty）用拉格朗日乘数法直接将 KL 散度的限制放进了目标函数中，这就变成了一个无约束的优化问题，即：

arg⁡max⁡θEθold[πθ(a∣s)πθold(a∣s)Aπθold(s,a)−βDKL[πθold(⋅∣s)∥πθ(⋅∣s)]]\mathop{\arg\max}_{\theta}\mathbb{E}_{\theta_{old}}\left[\frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)} A^{\pi_{\theta_{old}}}(s,a)-\beta D_{KL}\big[\pi_{\theta_{old}}(\cdot|s)\big\|\pi_\theta(\cdot|s)\big]\right] argmaxθ​Eθold​​[πθold​​(a∣s)πθ​(a∣s)​Aπθold​​(s,a)−βDKL​[πθold​​(⋅∣s)​πθ​(⋅∣s)]]

改成上述表达式以后，可以直接应用梯度上升法优化策略参数。但是这里还有个核心问题需要回答：这个 β\betaβ​（惩罚系数）该怎么确定？如果 β\betaβ 是个固定常数，会存在巨大的隐患：

  • 如果 β\betaβ 设得太大：惩罚太重，策略稍微更新就会被严重惩罚，导致训练缓慢。
  • 如果 β\betaβ 设得太小：惩罚太轻，起不到约束作用，就会导致新策略与旧策略相近的前提条件被打破。

而且，在训练的不同阶段，由于策略网络参数在变，相同的参数变化带来的 KL 散度波动是完全不同的。因此，β\betaβ 必须跟着训练进程动态调整。

OpenAI 的 PPO 论文中给出了一个启发式自适应算法，在每一次迭代中，算法会做两件事：

  1. 使用带拉格朗日惩罚项的目标函数，直接用普通的梯度上升（比如 Adam 优化器）更新参数 θ\thetaθ，持续训练几个 Epoch。

  2. 一轮训练结束后，计算新策略和旧策略之间真实的平均 KL 散度，记为 d=E[DKL]d = \mathbb{E}[D_{KL}]d=E[DKL​]，接着与 KL 散度约束的超参数 δ\deltaδ 进行对比，按照如下公式更新：

    β←{β/2,ifd<δ/1.5β×2,else\beta \leftarrow \begin{cases} \beta / 2, & \text{if} \quad d < \delta / 1.5 \\ \beta \times 2, & \text{else} \end{cases} β←{β/2,β×2,​ifd<δ/1.5else​

    简单理解为，当策略变化比预期小时，减小惩罚项；反之提高惩罚系数。

# PPO-Clip

相比于 PPO-Pnalty，工业界更喜欢 PPO - 截断（PPO-Clip）。因为 PPO-Penalty 里的系数 β\betaβ 需要在训练过程中动态根据 KL 散度的大小编码一套复杂的调整逻辑，而 PPO-Clip 相对更加简单。

PPO-Clip 提出了下面这个目标函数：

arg⁡max⁡θEθold[min⁡(πθ(a∣s)πθold(a∣s)Aπθold(s,a),clip(πθ(a∣s)πθold(a∣s),1−ϵ,1+ϵ)Aπθold(s,a))]\mathop{\arg\max}_{\theta}\mathbb{E}_{\theta_{old}}\left[\min\left(\frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)} A^{\pi_{\theta_{old}}}(s,a),\text{clip}\left(\frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)},1-\epsilon,1+\epsilon\right)A^{\pi_{\theta_{old}}}(s,a)\right)\right] argmaxθ​Eθold​​[min(πθold​​(a∣s)πθ​(a∣s)​Aπθold​​(s,a),clip(πθold​​(a∣s)πθ​(a∣s)​,1−ϵ,1+ϵ)Aπθold​​(s,a))]

其中 clip\text{clip}clip 函数的作用是将概率比值限制在 [1−ϵ,1+ϵ][1-\epsilon, 1+\epsilon][1−ϵ,1+ϵ] 的范围内。ϵ\epsilonϵ 是一个超参数，常见取值为 0.10.10.1 或 0.20.20.2。

当使用梯度上升法优化上述目标函数时，如果当前动作的优势 AAA 取值为正，那么新策略会提高该动作值的输出概率，反之则降低输出概率，符合直观理解。

当新策略与就策略的概率比值在 [1−ϵ,1+ϵ][1-\epsilon,1+\epsilon][1−ϵ,1+ϵ]，优化目标即为不带约束的 TRPO 优化目标，并且因为该概率比值在此范围内，所以可以认为符合 KL 散度不能过大的约束。而当概率比值超过这一区间后，上述优化目标变成一个常数，进而保证组织策略进一步更新。

# 广义优势估计

PPO 的策略更新依赖动作价值的优势估计，Advantage 的质量会直接影响训练稳定性。

最简单的一步 TD Advantage 是：

δt=rt+γVϕ(st+1)−Vϕ(st)\delta_t = r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t) δt​=rt​+γVϕ​(st+1​)−Vϕ​(st​)

这里 δt\delta_tδt​ 也可以看作 TD error。如果 δt>0\delta_t>0δt​>0，说明实际得到的结果比 Critic 预测更好；如果 δt<0\delta_t<0δt​<0，说明结果比 Critic 预测更差。

但是一步 TD 估计虽然方差较小，却可能有较大偏差。另一种做法是使用蒙特卡洛回报：

Gt=rt+γrt+1+γ2rt+2+⋯At=Gt−Vϕ(st)G_t=r_t+\gamma r_{t+1}+\gamma^2 r_{t+2}+\cdots\\ A_t=G_t-V_\phi(s_t) Gt​=rt​+γrt+1​+γ2rt+2​+⋯At​=Gt​−Vϕ​(st​)

蒙特卡洛估计偏差较小，但方差较大。强化学习中经常需要在偏差和方差之间做权衡。

广义优势估计（Generalized Advantage Estimation，GAE）正是为了解决这个问题。根据多步时序差分的思想，有：

At(1)=δt=−V(st)+rt+γV(st+1)At(2)=δt+γδt+1=−V(st)+rt+γrt+1+γ2V(st+2)At(3)=δt+γδt+1+γ2δt+2=−V(st)+rt+γrt+1+γ2rt+2+γ3V(st+3)⋮⋮At(k)=∑l=0k−1γlδt+l=−V(st)+rt+γrt+1+⋯+γk−1rt+k−1+γkV(st+k)\begin{aligned} A_t^{(1)} &= \delta_t &&= -V(s_t) + r_t + \gamma V(s_{t+1}) \\ A_t^{(2)} &= \delta_t + \gamma \delta_{t+1} &&= -V(s_t) + r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) \\ A_t^{(3)} &= \delta_t + \gamma \delta_{t+1} + \gamma^2 \delta_{t+2} &&= -V(s_t) + r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \gamma^3 V(s_{t+3}) \\ &\vdots &&\vdots \\ A_t^{(k)} &= \sum_{l=0}^{k-1} \gamma^l \delta_{t+l} &&= -V(s_t) + r_t + \gamma r_{t+1}+\dots+\gamma^{k-1} r_{t+k-1} + \gamma^k V(s_{t+k}) \end{aligned} At(1)​At(2)​At(3)​At(k)​​=δt​=δt​+γδt+1​=δt​+γδt+1​+γ2δt+2​⋮=l=0∑k−1​γlδt+l​​​=−V(st​)+rt​+γV(st+1​)=−V(st​)+rt​+γrt+1​+γ2V(st+2​)=−V(st​)+rt​+γrt+1​+γ2rt+2​+γ3V(st+3​)⋮=−V(st​)+rt​+γrt+1​+⋯+γk−1rt+k−1​+γkV(st+k​)​

GAE 将这些不同步数的优势估计进行指数加权平均，得到：

AtGAE=∑l=0∞(γλ)lδt+lA_t^{GAE}= \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l} AtGAE​=l=0∑∞​(γλ)lδt+l​

其中 γ\gammaγ 是折扣因子；λ∈[0,1]\lambda \in [0,1]λ∈[0,1] 用于控制 Bias-Variance Tradeoff。

  • 当 λ=0\lambda=0λ=0 时，GAE 接近一步 TD，方差较小但偏差较大。

  • 当 λ=1\lambda=1λ=1 时，GAE 接近蒙特卡洛估计，偏差较小但方差较大。

此外，PPO 实现中通常会对 Advantage 做标准化，让不同 batch 中的 Advantage 具有相近尺度，减少训练过程中的梯度波动。

A^t=At−μAσA+ϵ\hat A_t=\frac{A_t-\mu_A}{\sigma_A+\epsilon} A^t​=σA​+ϵAt​−μA​​

# PPO 的完整损失函数

PPO 实际训练时通常包含三个损失项：Actor loss、Critic loss、Entropy bonus。

Actor 的目标是最大化 clipped objective：

LCLIP(θ)=E[min⁡(rt(θ)A^t,clip⁡(rt(θ),1−ϵ,1+ϵ)A^t)]L^{CLIP}(\theta) = \mathbb{E} \left[ \min \left( r_t(\theta)\hat A_t, \operatorname{clip} \left( r_t(\theta), 1-\epsilon, 1+\epsilon \right) \hat A_t \right) \right] LCLIP(θ)=E[min(rt​(θ)A^t​,clip(rt​(θ),1−ϵ,1+ϵ)A^t​)]

在使用梯度下降实现时，通常写成最小化负数：

LCLIP(θ)=−E[min⁡(rt(θ)A^t,clip⁡(rt(θ),1−ϵ,1+ϵ)A^t)]L^{CLIP}(\theta)=-\mathbb{E}\left[\min \left(r_t(\theta)\hat A_t,\operatorname{clip}\left(r_t(\theta),1-\epsilon,1+\epsilon \right)\hat A_t\right)\right] LCLIP(θ)=−E[min(rt​(θ)A^t​,clip(rt​(θ),1−ϵ,1+ϵ)A^t​)]

Critic 的任务是让状态价值估计 Vϕ(st)V_\phi(s_t)Vϕ​(st​) 接近目标回报 RtR_tRt​。常见损失是均方误差：

Lcritic=E[(Vϕ(st)−Rt)2]L_{\text{critic}}=\mathbb{E}\left[\left(V_\phi(s_t)-R_t\right)^2\right] Lcritic​=E[(Vϕ​(st​)−Rt​)2]

其中 RtR_tRt​ 可以由折扣回报或 GAE 相关方法构造。

如果策略过早变得确定，智能体可能会陷入局部最优。为了鼓励探索，PPO 常常加入策略熵：

H(πθ(⋅∣st))=−Ea∼πθ[log⁡πθ(a∣st)]H(\pi_\theta(\cdot|s_t)) = - \mathbb{E}_{a\sim\pi_\theta} \left[ \log \pi_\theta(a|s_t) \right] H(πθ​(⋅∣st​))=−Ea∼πθ​​[logπθ​(a∣st​)]

熵越大，说明策略越随机，探索性越强。

最终 PPO 的损失函数常写为：

L=Lactor+c1Lcritic−c2H(πθ)L=L_{\text{actor}}+c_1 L_{\text{critic}}-c_2 H(\pi_\theta) L=Lactor​+c1​Lcritic​−c2​H(πθ​)

# 大模型后训练 PPO 算法

前面几节介绍的 PPO 主要是在传统强化学习环境中应用，例如 CartPole、Atari 游戏、机器人控制等。近几年，PPO 还有一个非常重要的应用场景：大语言模型的 RLHF 后训练。

RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）指的是：先让人类对模型输出进行偏好标注，再训练一个奖励模型来模拟人类偏好，最后用强化学习方法继续优化语言模型，使模型输出更符合人类偏好。

通常来说，一个完整的 RLHF 流程可以分为三步：

  1. 监督微调（Supervised Fine-tuning, SFT）：使用人工构造的高质量问答数据训练一个初始对话模型。
  2. 奖励模型训练（Reward Model, RM）：让人类对多个回答进行排序或比较，再训练一个奖励模型，用来判断某个回答是否更符合人类偏好。
  3. 强化学习优化（RL Optimization）：把 SFT 模型作为初始策略模型，用奖励模型给出的分数作为奖励，使用 PPO 等算法继续优化策略模型。

本节将从 PPO 算法出发理解 RLHF 中的强化学习过程。

# RLHF 的强化学习要素

在传统强化学习中，我们有状态、动作、奖励、策略、轨迹等概念。将这些概念映射到大语言模型后训练中，可以得到如下对应关系。

状态（State）：在大模型中，状态可以理解为当前上下文，即用户输入的 prompt 加上模型已经生成的部分 token。假设用户输入为 xxx，模型已经生成了 y<ty_{<t}y<t​，那么当前状态可以表示为 st=(x,y<t)s_t=(x,y_{<t})st​=(x,y<t​)。

动作（Action）：动作就是模型在当前状态下选择的下一个 token at=yta_t=y_tat​=yt​。

语言模型每一步都会从词表中选择一个 token，因此动作空间就是整个词表。相比 CartPole 只有两个动作，大模型的动作空间非常大，通常有几万到十几万个 token。

策略（Policy）：策略就是当前正在训练的语言模型。给定上下文 sts_tst​，模型输出下一个 token 的概率分布：

πθ(at∣st)=πθ(yt∣x,y<t)\pi_\theta(a_t|s_t) = \pi_\theta(y_t|x,y_{<t}) πθ​(at​∣st​)=πθ​(yt​∣x,y<t​)

所以，大语言模型本身就是一个参数化策略网络。

轨迹（Trajectory）：一次完整生成过程就是一条轨迹。对于一个 prompt xxx，模型依次生成 token：

y1,y2,…,yTy_1,y_2,\ldots,y_T y1​,y2​,…,yT​

对应的轨迹可以写为：

τ=(x,y1,y2,…,yT)\tau=(x,y_1,y_2,\ldots,y_T) τ=(x,y1​,y2​,…,yT​)

也就是说，一个 prompt-response pair 就可以看成强化学习中的一个 episode。

奖励（Reward）：传统强化学习中，奖励一般由环境直接给出。但在大模型后训练中，环境并不会直接告诉这个回答好不好。因此 RLHF 会额外训练一个奖励模型 rψ(x,y)r_\psi(x,y)rψ​(x,y)，用它来给完整回答打分 rψ(x,y)r_\psi(x,y)rψ​(x,y)。

如果回答更符合人类偏好，奖励模型输出更高；如果回答质量差、不符合指令、存在有害内容，奖励模型输出更低。

不过，实际 RLHF 中通常不会只使用奖励模型分数，还会加入一个 KL 惩罚项，限制当前策略不要偏离原始 SFT 模型太远：

r(x,y)=rψ(x,y)−βDKL(πθ(⋅∣x)∥πref(⋅∣x))r(x,y)=r_\psi(x,y)-\beta D_{KL}\left(\pi_\theta(\cdot|x)\|\pi_{\text{ref}}(\cdot|x)\right) r(x,y)=rψ​(x,y)−βDKL​(πθ​(⋅∣x)∥πref​(⋅∣x))

其中 πref\pi_{\text{ref}}πref​ 是参考模型，通常是冻结的 SFT 模型；β\betaβ 是 KL 惩罚系数。这样做的原因是：如果只最大化奖励模型分数，语言模型可能会学会钻奖励模型漏洞，生成一些奖励模型认为高分、但人类并不真正喜欢的文本。KL 惩罚项可以约束模型不要偏离原来的语言能力太远。

# 大模型 PPO 训练流程

大模型 RLHF 中的 PPO 训练，本质上就是把 “模型生成回答” 看成一次与环境交互，然后用奖励模型给这次交互打分，再用 PPO 更新语言模型。相比前面 CartPole 示例，这里的环境不再是一个显式的物理环境或游戏环境，而是由 prompt 数据集、奖励模型和参考模型共同构成的训练反馈系统。

整体流程可以分为以下几个阶段。

第一步，采样 prompt 并生成回答。

训练开始时，从 prompt 数据集中采样一批输入，例如用户问题、指令或对话上下文。然后使用当前策略模型生成回答。这里的策略模型就是正在训练的大语言模型。

在生成过程中，模型不是一次性输出完整回答，而是逐 token 生成。因此，每生成一个 token，都需要记录当前策略下这个 token 的 log probability。这个值后面会用于计算 PPO 中的新旧策略概率比值。

第二步，使用奖励模型给回答打分。

生成完整回答后，将 prompt 和 response 一起输入奖励模型。奖励模型会输出一个标量分数，用来表示这个回答是否符合人类偏好。

例如，对于同一个问题，如果回答更有帮助、更准确、更安全，奖励模型应该给出更高的分数；如果回答敷衍、错误、危险或不符合指令，奖励模型应该给出更低的分数。

需要注意的是，奖励模型通常是对完整回答打分，而不是对每个 token 单独打分。因此工程实现中常见的做法是：将奖励模型分数主要加在序列最后一个 token 上，再结合 KL 惩罚构造每个时间步的奖励。

第三步，计算与参考模型的 KL 惩罚。

从前面 TRPO 和 PPO 的推导可以看到，PPO 本身就强调不能让新旧策略变化过大。在大模型后训练中，这个问题更加重要。

原因在于，奖励模型只是人类偏好的近似，并不是真实的人类偏好本身。如果模型只追求奖励模型分数，可能会出现 Reward Hacking，即模型找到奖励模型的漏洞，生成一些表面上高分但实际质量不好的回答。此外，SFT 模型已经具备较好的语言能力、指令跟随能力和基础知识。如果 PPO 更新幅度过大，模型可能会为了追求某些偏好奖励而破坏原有能力。因此，大模型 RLHF 中通常会加入参考模型 KL 惩罚：

对于策略模型生成的同一段回答，同时计算这段回答在参考模型下的 log probability。然后比较当前策略模型和参考模型在这些 token 上的概率差异，得到 KL 惩罚。

这与 PPO-Clip 的思想是一致的：既希望策略朝着更高奖励方向更新，又不能让策略一次变化太大。只不过在大模型 RLHF 中，除了 PPO 自身的新旧策略概率比值约束，还额外使用参考模型约束模型不要偏离 SFT 初始策略太远。

第四步，使用价值模型估计 Advantage。

得到奖励以后，还需要判断每个 token 的生成动作到底比平均水平好多少。这就需要价值模型参与。

价值模型会对每个生成位置估计一个状态价值，即在当前上下文条件下，后续大概还能获得多少奖励。然后结合真实奖励，使用 GAE 公式计算 Advantage。

第五步，使用 PPO 更新策略模型和价值模型。

有了旧策略生成的数据、奖励、价值估计和 Advantage 后，就可以进入 PPO 更新阶段。更新策略模型时，会比较当前策略和旧策略对同一批 token 的概率差异，并使用 PPO-Clip 限制更新幅度。

如果某个 token 的 Advantage 为正，说明它对最终回答质量有正向贡献，PPO 会倾向于提高该 token 在对应上下文中的生成概率；如果 Advantage 为负，则会降低它的生成概率。但无论提高还是降低，PPO 都不会允许策略在一次更新中变化过大。

与此同时，价值模型也会被更新，使其之后能更准确地预测不同生成状态下的期望奖励。

完成若干轮 PPO 更新后，当前策略模型会变成新的旧策略模型，再进入下一轮 prompt 采样和回答生成。整个 RLHF-PPO 训练就是不断重复这个过程。
